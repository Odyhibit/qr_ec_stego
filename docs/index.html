About QR Code Steganography

This tool demonstrates steganographic techniques for hiding secret messages within QR codes. Messages can be hidden in two locations:

  • Padding Bytes: Unused space in the data region that's normally filled with zeros
  • Error Correction Codes (ECC): Reed-Solomon error correction bytes that can be partially compromised while maintaining scanability

The QR code will scan normally and display the decoy message, while hiding additional data that can only be extracted with specialized tools.

Created for educational and security research purposes. Use responsibly.
